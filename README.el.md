# AI Video Studio For Windows

Windows εφαρμογή που φτιάχνει AI videos από prompt (ελληνικά ή αγγλικά). Η παραγωγή τρέχει σε cloud GPU στο **Vast.ai Serverless** με **Wan 2.2** (open-source, Apache 2.0). Δεν πληρώνεις όταν δεν παράγεις. Τα videos σώζονται **τοπικά στον υπολογιστή σου**.

## Εγκατάσταση

1. Τρέξε το `AI Video Studio For Windows_0.1.0_x64-setup.exe` (ανά χρήστη, **χωρίς admin**, ~3 MB).
2. Αν τα Windows δείξουν «Windows protected your PC» (ο installer δεν έχει πληρωμένο certificate): **More info → Run anyway**.
3. Το WebView2 που χρειάζεται η εφαρμογή **εγκαθίσταται αυτόματα** από τον installer αν λείπει.

Δεν χρειάζεται Python, Node ή οτιδήποτε άλλο στον υπολογιστή.

## Πού βάζω τα κλειδιά

Όλα στην εφαρμογή → **Ρυθμίσεις**. Αποθηκεύονται στο **Windows Credential Manager** του χρήστη (όχι σε αρχείο, δεν εμφανίζονται ξανά). Κάθε υπηρεσία έχει **Test Connection**.

| Τι | Πού βρίσκεται | Υποχρεωτικό |
|---|---|---|
| **Vast.ai API key** + όνομα endpoint (`comfyui-json`) | cloud.vast.ai → Account → API Keys | ναι |
| **Βελτίωση prompt** | διάλεξε έναν πάροχο παρακάτω | όχι |

### Βελτίωση prompt: πάροχοι και tokens

| Πάροχος | Κλειδί | Κόστος σε tokens συνδρομής Claude |
|---|---|---|
| **Claude Code συνδρομή** (προεπιλογή) | κανένα: χρησιμοποιεί το login του `claude` | ≈0,9k tokens ανά «Βελτίωσε» με `haiku` |
| **Google Gemini** | aistudio.google.com/apikey (έχει δωρεάν tier) | **0** |
| **OpenAI-compatible** (OpenAI, OpenRouter, Groq, Ollama, LM Studio) | API key και Base URL | **0** |
| Anthropic API | console.anthropic.com | 0 (πληρώνεις API) |

Για το Claude Code πρέπει να είναι εγκατεστημένο και να έχεις κάνει login μία φορά (`claude` σε terminal). Η εφαρμογή το καλεί χωρίς tools, χωρίς MCP/skills/CLAUDE.md, χωρίς αποθήκευση session και με σύντομο system prompt, ώστε να καταναλώνει όσο λιγότερα γίνεται. Το πραγματικό πλήθος tokens εμφανίζεται μετά από κάθε βελτίωση. Για μηδενική κατανάλωση συνδρομής διάλεξε Gemini.

### Αποθήκευση: τοπικά αντί για R2

Προεπιλογή: το video γυρνάει μέσα στην απάντηση του worker και σώζεται απευθείας στον φάκελο εξόδου. **Δεν χρειάζεται R2.** Απαιτεί μία φορά **Μοντέλα → «Εγκατάσταση στους workers»** (εγκαθιστά ένα μικρό ComfyUI node). Αν δεν έχει γίνει, η εφαρμογή πέφτει αυτόματα στο R2/S3 (αν υπάρχει στα Vast env vars: `S3_ACCESS_KEY_ID`, `S3_SECRET_ACCESS_KEY`, `S3_BUCKET_NAME`, `S3_ENDPOINT_URL`).

### Να κατεβαίνει στο μηδέν

Το endpoint πρέπει να έχει `cold_workers = 0` και `min_load = 0`. Ρυθμίσεις → **«Εφάρμοσε scale-to-zero»** τα ορίζει, και το Test Connection σε προειδοποιεί αν δεν ισχύει.

## Χρήση

- **Δημιουργία**: διάλεξε τρόπο, γράψε prompt, *Generate*. Φάσεις: Ουρά → Εκκίνηση worker → Παραγωγή → Αποθήκευση → Έτοιμο. Η πρώτη παραγωγή μετά από αδράνεια αργεί 1-3 λεπτά.
- **Εικόνα → Video**: στη «Δημιουργία» πάτα την καρτέλα «Εικόνα → Video» (ή απλά σύρε μια εικόνα). Εμφανίζονται μόνο τα μοντέλα που δέχονται εικόνα και λέει πόσες εικόνες θέλει το καθένα. Αν το μοντέλο δεν είναι εγκατεστημένο στους workers, σου το λέει και σε πάει στα Μοντέλα.
- **Πρόσθεσε μοντέλο**: Μοντέλα → «Πρόσθεσε μοντέλο». Γράψε όνομα (π.χ. «wan 2.2 image to video») ή κάνε επικόλληση link από το HuggingFace, διάλεξε αρχεία, πάτα «Πρόσθεσε» και μετά «Εγκατάσταση στους workers». Για να παράγει χρειάζεται και workflow: «Πρόσθεσε workflow (.json)» (ComfyUI → Export (API)).
- **✨ Βελτίωσε το prompt**: μετατρέπει μια σύντομη ιδέα σε κινηματογραφικό prompt για Wan 2.2 (με αναίρεση).
- **Πολλά prompts**: τσέκαρε την επιλογή και γράψε ένα ανά γραμμή· τρέχουν διαδοχικά και η ουρά επιβιώνει σε restart.
- **Projects**: σελίδα *Projects*. Κάθε project έχει **δικό του φάκελο που διαλέγεις εσύ** (αλλιώς: φάκελος εξόδου/όνομα), δικό του **στυλ** που προστίθεται σε κάθε prompt (π.χ. «cinematic, warm tones») και επιλογή να σώζεται το prompt σε `.txt` δίπλα σε κάθε video. Αλλάζεις project από το μενού πάνω αριστερά.
- **Βιβλιοθήκη**: player, prompt, κόστος, άνοιγμα φακέλου, διαγραφή.
- **GPU & Κόστος**: ζωντανές τιμές $/ώρα από το Vast, επιλογή καρτών που εφαρμόζεται στο endpoint.
- **Μοντέλα**: κατάλογος open-source (Wan 2.2 T2V/I2V/TI2V 5B, FLUX.1 schnell, SDXL) με μέγεθος, VRAM, άδεια.

Τα videos πάνε στον φάκελο του project. Αν δεν έχεις ορίσει, στο `Βίντεο\AI Video Studio\<project>\` (ο προεπιλεγμένος φάκελος αλλάζει στις Ρυθμίσεις).

## Εγκατάσταση μοντέλων και dependencies στους workers

Μοντέλα → τσέκαρε ό,τι θέλεις → **«Εγκατάσταση στους workers»**. Η εφαρμογή:

1. φτιάχνει script που κατεβάζει τα αρχεία (URL από HuggingFace, επαληθευμένα), τα custom nodes με τα requirements τους, και το node της τοπικής αποθήκευσης,
2. δημιουργεί **ιδιωτικό αντίγραφο** του template σου («AIVS …») με το script μπροστά από τις εντολές του και αυξάνει τον δίσκο όσο χρειάζεται,
3. δείχνει το endpoint σου σε αυτό το template.

Το αρχικό template δεν αλλάζει. Ισχύει για **νέους** workers (οι ζεστοί δεν αλλάζουν μέχρι να κατέβουν). Το «Προεπισκόπηση script» δείχνει τι θα τρέξει πριν εφαρμόσεις τίποτα.

## Νέοι τρόποι παραγωγής (χωρίς αλλαγή κώδικα)

Ρίξε ένα `.json` στον φάκελο workflows (Μοντέλα → «Άνοιγμα φακέλου», δηλ. `%APPDATA%\com.aivideostudio.app\workflows`) και πάτα *Ανανέωση*. Δύο μορφές:

1. **Export από το ComfyUI** (Save → API Format): το prompt μπαίνει στο θετικό `CLIPTextEncode`.
2. **Με περιγραφή** `{ "meta": {...}, "workflow": {...} }`: placeholders `"{{key}}"` στο workflow και πεδία στο `meta.inputs` (`text`/`int`/`float`/`seed`, default, min, max). Παραδείγματα: `app/src-tauri/workflows/wan22-t2v-*.json`.

Τα μοντέλα και τα nodes που χρειάζεται ένα workflow πρέπει να υπάρχουν στον worker. Αν είναι στον κατάλογο μοντέλων, τα εγκαθιστά το κουμπί παραπάνω.

## Για φίλο / άλλον υπολογιστή

Δεν υπάρχει τίποτα δεμένο με τον δικό σου υπολογιστή. Ο φίλος χρειάζεται τον installer, **δικό του** λογαριασμό Vast με δικό του endpoint (template «ComfyUI Serverless Wan 2.2») και δικά του κλειδιά. Αλλιώς πληρώνεις εσύ. Τα κλειδιά δεν εξάγονται ποτέ· το Εξαγωγή/Εισαγωγή ρυθμίσεων περνά μόνο μη-μυστικές ρυθμίσεις.

## Γνωστά όρια (ειλικρινά)

- **Δεν έχει γίνει πραγματική παραγωγή video**: δεν υπήρχαν κλειδιά Vast. Επαληθεύτηκαν: build και installer, unit tests, η κλήση Claude Code (πραγματική), το `/route/` του Vast (λάθος key → error), και **48 έλεγχοι end-to-end** της πραγματικής εφαρμογής απέναντι σε τοπικό ψεύτικο Vast server (`app/tests/e2e`): cold start, ουρά 3 prompts, αποθήκευση στον φάκελο του project, ακύρωση, αποτυχία/retry, fallback σε R2, GPU, εγκατάσταση template, όλες οι σελίδες σε σκούρο/φωτεινό. Ο ψεύτικος server είναι γραμμένος από εμάς βάσει docs, άρα δεν αποδεικνύει ότι ο πραγματικός worker συμπεριφέρεται ακριβώς έτσι.
- **Τοπική αποθήκευση** και **«Εγκατάσταση στους workers»** βασίζονται σε API/συμπεριφορά που τεκμηριώνεται στο SDK αλλά δεν δοκιμάστηκε σε ζωντανό endpoint. Αν κάτι αποτύχει, η εφαρμογή πέφτει στο R2 και δείχνει το σφάλμα του Vast.
- Το `/generate/sync` είναι blocking: δεν υπάρχει ζωντανό ποσοστό, μόνο φάση και χρόνος.
- Το «Γρήγορο (Lightning 4 steps)» συνδέει τα LightX2V LoRA με `LoraLoaderModelOnly` (4 steps, cfg 1). Το doc δεν δίνει έτοιμο workflow με LoRA, οπότε η σύνδεση είναι δική μας. Αν το αποτέλεσμα δεν σε ικανοποιεί, δοκίμασε «Ποιότητα (20 steps)».
- Η σύνδεση στους workers χρησιμοποιεί το root certificate του Vast· αν τα Windows το απορρίψουν, ξαναδοκιμάζει χωρίς έλεγχο αλυσίδας (το αίτημα παραμένει υπογεγραμμένο από το Vast).
- Η εκτίμηση κόστους = τιμή GPU × χρόνος (χρόνος εκτιμώμενος για κάρτα κλάσης RTX 4090)· το πραγματικό κόστος κάθε clip φαίνεται στη Βιβλιοθήκη.

## Για προγραμματιστές

Tauri 2 (Rust) + Svelte 5. `cd app && npm install && npm run tauri dev`. Installer: `npm run tauri build` → `app/src-tauri/target/release/bundle/nsis/`. Tests: `cd app/src-tauri && cargo test` (`-- --ignored` για το πραγματικό Claude Code). Πρωτόκολλο Vast και αποφάσεις: `PLAN.md`.
